# StrongFireGameBot 🔥

Full modular Telegram PvP game foundation.

## Included
- Group 1v1 matchmaking
- `/fire`
- 200 HP
- Random damage
- 30-second turn timeout with automatic opponent win
- Player profile
- Stars and Rank Stars as separate values
- Rank
- Leaderboard
- Owner / CEO / Admin / Moderator permission hierarchy
- Star and Rank Star management
- Railway-ready deployment
- SQLite database

## Environment variables
`BOT_TOKEN` = Telegram bot token  
`OWNER_ID` = numeric Telegram user ID of the bot owner

Never commit tokens to GitHub.
